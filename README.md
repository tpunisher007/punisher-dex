# Punisher-DEX-on-arc


A decentralized exchange (DEX) prototype built to explore modern Web3 technologies, decentralized trading interfaces, and wallet integration.

> ⚠️ This project is currently under active development and is intended for learning, experimentation, and portfolio purposes.

---

## ✨ Features

- 💱 Token Swap Interface
- 📈 Trading Dashboard
- 📊 Market Overview
- 🔗 Wallet Connect (Planned)
- 📱 Responsive Design
- 🌙 Modern Dark UI

---

## 🛠️ Tech Stack

- CSS3
- JavaScript
- Git & GitHub
